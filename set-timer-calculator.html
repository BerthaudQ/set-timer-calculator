Your set

Add tracks from the library to start building your set.

Import your playlist as .txt and, if you like, the full collection as .xml — the tool automatically matches the tracks from the playlist to the collection to pre-fill their in/out points with memory cues and hot cues. A track that isn't found (different title/artist between the two exports) keeps times you can set by hand. The overlap field is optional: leave it at 0:00 if your out point already matches exactly when you start the next track. Nothing is ever sent anywhere: all the calculation happens in your browser.
