# Set Timer Calculator

Set Timer Calculator is a JavaScript script and user interface that lets you build a playlist of tracks and calculate its total duration based on the selected cue points.

## How to use

1. Open `set-timer-calculator.html` in your browser.
2. Import your Rekordbox collection in XML format.
3. Either import a playlist in TXT format or select tracks directly from the collection.
4. Select the cue points to use and check the calculated total set duration.

Importing both the playlist and collection lets the tool match playlist tracks with the collection and use their cue points.

## Supported formats

Only collection and playlist exports from Rekordbox are supported:

- Collection: XML export
- Playlist: TXT export
